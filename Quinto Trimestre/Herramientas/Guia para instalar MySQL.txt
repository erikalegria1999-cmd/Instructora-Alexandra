📌 Guía Paso a Paso: Conectar MySQL con Node.js

🛠️ Prerrequisitos

Antes de empezar, asegúrate de cumplir con los siguientes puntos:

Tener Node.js instalado en tu equipo.

Tener el servicio de MySQL ejecutándose (mediante XAMPP, MySQL Workbench o servicios del sistema).

Tener creada previamente la base de datos (en este ejemplo: Ejemplo).

🚀 Pasos de Configuración

Paso 1: Instalar la dependencia
Abre la terminal en la carpeta de tu proyecto y ejecuta el siguiente comando para instalar la librería oficial recomendada:
npm install mysql2
Paso 2: Crear y probar la conexión
Crea un archivo llamado app.js (o index.js) e incluye el siguiente código:
// 1. Importar el módulo de MySQL
const mysql = require('mysql2');

// 2. Definir los datos de acceso a la Base de Datos
const conectar = mysql.createConnection({
    host: "127.0.0.1",   // Dirección del servidor local (localhost)
    user: "root",        // Usuario de tu MySQL
    password: "Santi09.",// Tu contraseña de MySQL
    database: "Ejemplo", // Nombre exacto de tu base de datos
    port: 3306           // Puerto predeterminado de MySQL
});

// 3. Probar y verificar si la conexión fue exitosa
conectar.connect((error) => {
    if (error) {
        console.log("❌ Error al conectar a la base de datos:");
        console.log(error.message); // Muestra la causa exacta del error
    } else {
        console.log("✅ ¡Conexión realizada con éxito!");
    }
});

5. EXPLICACIÓN DETALLADA DEL CÓDIGO
A. Captura de Datos (req.body):
   • req.body: Contiene la información enviada desde el cliente (formulario o Postman) en formato JSON.
   • Destructuring { nombre, apellido... }: Extrae cada dato en su propia variable para facilitar su uso.

B. La Consulta SQL y los comodines (?):
   • INSERT INTO usuario(...): Especifica la tabla y las columnas donde se guardará la información.
   • VALUES (?,?,?,?): Los signos '?' funcionan como marcadores de posición (placeholders).
     - SEGURIDAD: Evitan ataques de Inyección SQL (SQL Injection).
     - LIMPIEZA: Escapan caracteres especiales de forma automática.

C. El Arreglo de Variables [nombre, apellido, direccion, telefono]:
   • Sustituye los signos '?' en el mismo orden exacto en el que fueron colocados dentro de la consulta SQL.

D. Respuesta de MySQL (error, resultado):
   • error: Devuelve los detalles si la inserción falla (ej. tabla no existe, campos faltantes).
   • resultado: Contiene la confirmación de MySQL si la inserción fue exitosa.

E. Respuesta al Cliente (res.json):
   • Devuelve un mensaje JSON informando si el usuario fue registrado correctamente o si ocurrió un error.
